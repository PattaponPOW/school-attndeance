ระบบบันทึกและสถิติเปอร์เซ็นต์การมาเรียนของนักเรียน (แยกชาย-หญิง) • รองรับการซิงก์ข้อมูลผ่าน Firebase Realtime Database

ตั้งค่าเชื่อมต่อ Firebase Realtime Database

วิธีเชื่อมต่อแบบง่ายที่สุด:

1. กดปุ่มคัดลอกโค้ดจากหน้า Firebase Console (ส่วน Add Firebase SDK)

2. นำโค้ดทั้งหมดมาวางลงในช่องด้านล่างนี้ได้เลย ระบบจะดึงค่า firebaseConfig และ databaseURL ให้อัตโนมัติครับ

* ระบบจะดึงค่าอัตโนมัติทันทีที่คุณวางโค้ดด้านบน
